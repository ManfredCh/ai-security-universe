## B.4 — How to use this appendix

This appendix registers material found between the 2026-09-26 search and a search on 2026-10-25.
The taxonomy axis, the defence families and the refusal to pool incomparable results are unaffected.
What changes is the **evidence state**: disclosure is now a running channel, the toolchain is the
busiest compromised surface, and offensive use is documented with actors and unit costs. When citing
this survey, cite the retrieval freeze date, Appendix A's date and this appendix's date together.
